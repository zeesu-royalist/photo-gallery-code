# Ethan Vale archive

`npm install && npm run dev`

- `components/Archive.tsx` — markup (JSX), starts the engine once on mount
- `lib/archive.ts` — 3D sphere, drag, scroll dolly, grid, lightbox, menu, cursor (ported from the static page, `@ts-nocheck`)
- `lib/photos.ts` — typed photo data
- `app/globals.css` — Tailwind layers + the page CSS
